# DSH 模型路由与账号余额故障排查

> 适用：DSH Desktop 报 `本轮运行失败 4xx/5xx: ...` 且带 `QUOTA` / `RATE_LIMIT` / `MISSING_CREDENTIAL` 等标记时。
> 最近更新：2026-09-17（源起一次 402 故障排查）

---

## 一、一句话结论模板

DSH 报的 4xx 大多是**上游账号问题**，不是 DSH 或插件问题。
排查方向永远是：**先看路由指向哪个 provider → 再拿 key 直连上游测**。

本次结论：`provider: xiaomi`（小米 MiMo）返回 HTTP 402 `insufficient_balance`，账号余额为 0；
备用 DeepSeek key 也已欠费（-0.72 CNY）。**两把 key 同时空了**，与 DSH 无关。

**最终落点**：轮换到 **阿里云百炼免费额度**（`provider: dashscope` / `qwen3.8-flash`），
理由是账号开了「免费额度用完即停」→ **200 即免费、403 即拒付，不存在悄悄扣钱**；
且百炼有 **13 个模型**免费额度未耗尽且支持 tool calling，够轮换很久。OpenRouter 免费档（50 次/天）留作备用。

## 二、实现链路（先搞清谁在发请求）

```
~/.dsh/settings.yaml
  llm-pi-ai.providers.{<路由名>}
  agent-default-model.{provider, model}
        │
        ▼
@deepseek-ai/dsh-llm-pi-ai        （DSH 的 LLM 适配层，负责把路由映射成 pi-ai 的 provider）
        │
        ▼
@earendil-works/pi-ai             （真正持有各家 baseUrl / 模型目录，41 个 provider）
  dist/providers/<name>.js        ← baseUrl 与 env key 名都在这里
  dist/providers/data/<name>.json ← 模型目录（上下文窗口、单价、compat）
        │
        ▼
上游 API（小米 / DeepSeek / OpenRouter / 百炼 ...）
```

**要点**：`settings.yaml` 里只写 `apiKeyEnv` 就够了 —— 前提是路由名能在 pi-ai 里找到（41 个内置之一）。
pi-ai 没有的路由（如裸 `dashscope`）必须自己把 `api`、`baseURL`、`models` 全部写全，否则写入时就被拒。

### 关键文件位置（Windows）

| 用途 | 路径 |
|---|---|
| 模型路由 / 默认模型 | `%USERPROFILE%\.dsh\settings.yaml` |
| 密钥引用表 | `%USERPROFILE%\.dsh\.credentials.yaml`（`refs:` 段） |
| pi-ai provider 定义 | `D:\Program Files\DSH Desktop\resources\app\node_modules\@earendil-works\pi-ai\dist\providers\` |
| DSH 的 pi-ai 适配层 | `...\node_modules\@deepseek-ai\dsh-llm-pi-ai\lib\index.js`（schema 在第 960-1015 行附近） |

## 三、5 分钟排查 SOP

### Step 1　找到当前路由

```bash
head -10 "$USERPROFILE/.dsh/settings.yaml"
# 看 llm-pi-ai.providers 和 agent-default-model
```

### Step 2　查这个路由打到哪

```bash
cat "D:/Program Files/DSH Desktop/resources/app/node_modules/@earendil-works/pi-ai/dist/providers/<路由名>.js"
# 拿 baseUrl 和 envApiKeyAuth 里的 key 名
```

### Step 3　拿 key 直连上游测（**决定性一步**）

```bash
# OpenAI 兼容端点通用探针。注意国内端点要 --noproxy '*'，否则可能被代理带偏
curl -s -m 60 --noproxy '*' -w "\nHTTP=%{http_code}\n" \
  -H "Authorization: Bearer <KEY>" -H "Content-Type: application/json" \
  -d '{"model":"<MODEL>","messages":[{"role":"user","content":"hi"}],"max_tokens":8}' \
  <BASE_URL>/chat/completions
```

判别法：

| 现象 | 含义 | 解法 |
|---|---|---|
| `402 insufficient_balance` | 账号余额为 0 | 充值，或换路由 |
| `401 invalid key` | key 错/被删 | 换 key |
| `200` 但模型 404 | 模型名过期 | 查 `/v1/models` 换模型 |
| 连不上 / 超时 | 网络或需代理 | 试加/去掉 `--noproxy` |
| `403 FreeTierError` | 免费档被限客户端 | 换 provider（见第八节坑 3） |
| `403 AllocationQuota.FreeTierOnly` | **免费额度已耗尽**（其实是好事，见第六节） | 轮换到同路由另一个模型，不用改 key |

### Step 4　顺便查余额（有官方接口的话）

```bash
# DeepSeek
curl -s --noproxy '*' -H "Authorization: Bearer <KEY>" https://api.deepseek.com/user/balance
# OpenRouter（返回 free_model_daily_requests 等关键配额）
curl -s --noproxy '*' -H "Authorization: Bearer <KEY>" https://openrouter.ai/api/v1/key
```

### Step 5　理解 DSH 的错误码

pi-ai 适配层对上游失败的分类（见 dsh-llm-pi-ai README）：

| code | 含义 | 能否重试 |
|---|---|---|
| `QUOTA` | **终止性**失败（402、余额耗尽） | ❌ 重试无用，必须换/充值 |
| `RATE_LIMIT` | 暂时性限流 | ✅ 可重试 |
| `MISSING_CREDENTIAL` | `apiKeyEnv` 解析为空 | ❌ 补 key |
| `INVALID_CREDENTIAL` | key 存在但不可用 | ❌ 换 key |
| `UNKNOWN_MODEL` | 模型名不在目录里 | ❌ 改模型名 |

> **看到 `QUOTA` 就别再重试了** —— 那是 DSH 在告诉你「这是硬失败」。

## 六、阿里云百炼免费额度路由（推荐主力）

### 6.1 「仅使用免费额度」模式 = 天然的防扣费保险

百炼账号可开启 **「免费额度用完即停」**。本机账号已开启，表现在 API 上：

| 返回 | 含义 |
|---|---|
| **HTTP 200** | 走的是**免费额度**，100% 不产生按量扣费 |
| **HTTP 403 `AllocationQuota.FreeTierOnly`** | 该模型免费额度已耗尽，且被拒绝按量付费 |

403 原文：

```json
{"error":{"message":"Free quota exhausted. To continue accessing the model on a paid basis,
 please add funds or disable the \"use free tier only\" mode in the management console.",
 "type":"AllocationQuota.FreeTierOnly"}}
```

> **这意味着可以放心大胆地跑**：要么 200 用免费额度，要么 403 被拒——**不存在「悄悄扣钱」的中间态**。

### 6.2 免费额度规则

| 规则 | 内容 |
|---|---|
| 额度 | 新用户**每个模型** 100 万 tokens（输入/输出各 100 万），覆盖 70+ 模型 |
| 有效期 | **90 天**，过期不补发、不延期、不重置 |
| 地域 | **仅华北2（北京）** 的实时推理调用（`dashscope.aliyuncs.com` 即北京端点，天然符合） |
| 独立性 | 不同模型额度**互相独立、不可跨模型使用** |
| 抵扣顺序 | 免费额度 > 资源包 > 节省计划 > 按量付费 |

### 6.3 免费额度盘点（2026-09-17 实测）

**✅ 额度未耗尽 + 支持 tool calling（可直接用，13 个）**

| 模型 id | 定位 |
|---|---|
| `qwen3.8-flash` | **已设为默认**。1M 上下文、多模态、官方定位「高并发智能体」 |
| `qwen3.8-2.4t-a95b` | 2.4T 参数 MoE 旗舰（开源版），纯文本重度推理最强 |
| `qwen3.7-max` | Max 档，复杂文本推理、知识库问答 |
| `qwen3-max` | 前沿推理，1T+ 参数 |
| `qwen3.8-27b` | 中等复杂度多模态，办公自动化 |
| `qwen3.5-flash` / `qwen-flash` / `qwen3-coder-flash` / `qwen3-vl-flash` | 轻量档，快 |
| `qwen-plus` | 生产常用均衡档 |
| `deepseek-v4.1-flash` | DeepSeek 系 |
| `kimi-k3` | 长文本 |
| `glm-5.3` | GLM 系 |

**❌ 免费额度已耗尽**：`qwen3.8-max`、`qwen3.7-flash`、`qwen3.6-flash`、`deepseek-v4-pro`

**⚠️ 未开通（需先在百炼控制台激活该商品）**：`ZHIPU/GLM-5.3-Flash`、`MiniMax/MiniMax-M3`、`stepfun/step-3.7-flash`
→ 报 `400 The product is not activated`

### 6.4 轮换策略（关键洞察）

> **免费额度按 token 计，不按钱计** —— 烧掉 100 万 tokens 的额度，跟你用旗舰档还是 Flash 档无关。
> 所以**优先用最强的模型**，额度耗尽再轮换到下一个，才是最优解。

配置里已把 13 个模型全部声明进 `models:` 列表 → 它们会直接出现在 DSH 的**模型选择器**里，
**轮换 = UI 里点一下**，不用改配置文件。

### 6.5 配置写法（`settings.yaml`）

```yaml
llm-pi-ai:
  providers:
    dashscope:                                    # 非 pi-ai 内置路由 → 三件套必须写全
      apiKeyEnv: DASHSCOPE_API_KEY
      displayName: 阿里云百炼
      api: openai-completions                     # 协议
      baseURL: https://dashscope.aliyuncs.com/compatible-mode/v1
      defaultContextWindow: 131072
      defaultMaxTokens: 32768
      models:
        - id: qwen3.8-flash
          name: Qwen3.8-Flash
        # ... 其余 12 个同格式
agent-default-model:
  provider: dashscope
  model: qwen3.8-flash
```

`.credentials.yaml`：

```yaml
refs:
  DASHSCOPE_API_KEY: "sk-..."
```

**说明**：`compat` 字段刻意不写 —— pi-ai 对未指定的字段有**自带探测**（README：*a field no layer decides falls through to pi-ai's own detection*）。少写一个字段就少一个出错面。
`qwen3.8-flash` 实际支持 1M 上下文，这里刻意保守设 131072；需要长上下文时把 `defaultContextWindow` 提到 `1000000` 即可。

## 七、切路由怎么改（以本次为例）

### `.credentials.yaml` 加引用

```yaml
refs:
  XIAOMI_API_KEY: "sk-..."
  OPENROUTER_API_KEY: "sk-or-v1-..."
```

### `settings.yaml` 加路由 + 改默认模型

```yaml
llm-pi-ai:
  providers:
    xiaomi: { apiKeyEnv: XIAOMI_API_KEY }              # 保留，充值后可随时切回
    openrouter: { apiKeyEnv: OPENROUTER_API_KEY }      # pi-ai 内置路由，只写 apiKeyEnv 即可
agent-default-model:
  provider: openrouter
  model: "nvidia/nemotron-3-ultra-550b-a55b:free"      # 含冒号，务必加引号
```

**注意事项**

1. **不用重启 DSH**。`dsh-settings-file` 用 chokidar 监听配置文件，外部编辑会热发布（README 原话：*external edits hot-publish through the seam*）。
2. **不会被应用回写覆盖**。写入走「跨进程 writer lock + 重读 + 注释保留的叶子级 diff」，手工编辑是安全的。
3. **改完请新建会话**。已有会话可能绑定着旧路由，`agent-default-model` 只影响新建会话；保险做法是在模型选择器里显式选一次。
4. 模型名带 `:` 的（`:free` 后缀）**必须加引号**，否则 YAML 解析会踩坑。
5. 改完用 `js-yaml` 解析一遍确认语法没坏：

```bash
NODE_PATH="$USERPROFILE/.dsh/profiles/desktop/node_modules" node -e "
const yaml=require('js-yaml'),fs=require('fs');
console.log(Object.keys(yaml.load(fs.readFileSync(process.env.USERPROFILE+'/.dsh/settings.yaml','utf8'))['llm-pi-ai'].providers));
"
```

### 回滚

```bash
cd "$USERPROFILE/.dsh"
cp settings.yaml.bak-<时间戳> settings.yaml
cp .credentials.yaml.bak-<时间戳> .credentials.yaml
```

备份留存：

| 时间戳 | 状态 |
|---|---|
| `20260917155618` | 小米 MiMo（余额耗尽现场） |
| `20260917162012` | 已切 OpenRouter 免费档 |

## 八、踩过的坑

1. **`QUOTA` ≠ `RATE_LIMIT`**。DSH 对 402 判定为终止性失败，重试一百次也是 402。看到 `QUOTA` 直接去查钱。
2. **余额按账号算，免费额度按模型算** —— 这两件事方向相反，别搞混：
   - 小米 MiMo：`mimo-v2.5`（便宜档）与 `mimo-v2.5-pro` **同样 402**，因为余额是整个账号的。
   - 百炼：`qwen3.8-flash` 有额度、`qwen3.7-flash` 已耗尽，**同一把 key 同一个账号，结果不同**，因为额度按模型独立。
3. **OpenCode Zen 的免费档（big-pickle 等）第三方客户端用不了**：
   ```
   403 {"type":"error","error":{"type":"FreeTierError",
        "message":"OpenCode's free tier can only be used from within OpenCode"}}
   ```
   免费模型列表里 `opencode` 家看着很香（big-pickle / mimo-v2.5-free / nemotron-3-ultra-free 等 7 个 $0），
   但被锁在官方客户端内，**DSH 走不通**。要零成本请走 OpenRouter 的 `:free` 或百炼免费额度。
4. **免费模型会随时下架/转付费**。`:free` 后缀的 slug 不稳定，配好后若某天突然 404，先查是不是转付费了（OpenRouter 的报错会直接给出付费 slug）。
5. **百炼上「模型在列表里」≠「你能调」**。253 个模型里有三种状态，**唯一可靠的判别方式就是实测**，别照文档配：
   - 正常可用 → HTTP 200
   - 免费额度耗尽 → `403 AllocationQuota.FreeTierOnly`
   - 商品未开通 → `400 The product is not activated`（要去控制台激活该商品，如 MiniMax / 智谱 / 阶跃）
6. **百炼免费额度有 90 天有效期**且按模型独立。看到 `403 AllocationQuota.FreeTierOnly` 就是该模型额度空了，换同路由另一个模型即可，**不用改 key**。
7. **国内端点加 `--noproxy '*'`，海外端点两种都试**。本次小米/百炼直连才行；openrouter 直连和代理都通。
8. **OpenRouter 免费档 50 次/天**（账号充值满 $10 后升到 1000/天）。agent 一次复杂任务就可能吃掉 20-50 次请求，长期当主力要考虑充值。

## 九、候选路由备忘

pi-ai 内置 41 个 provider，其中**「套餐制、目录标价显示 $0」**的几条值得留意（不是免费，是包月）：

- `xiaomi-token-plan-cn` → `token-plan-cn.xiaomimimo.com/v1`（小米 Token 套餐，含 mimo-v2.5 / pro）
- `qwen-token-plan-cn` → 通义 Token 套餐（含 deepseek-v4、glm-5.x、kimi-k2.x、qwen3.7/3.8 等一大批）
- `zai` / `zai-coding-cn` → GLM 高速版

这些都要**单独的套餐 key**，与 pay-as-you-go 的 key 不通用。
