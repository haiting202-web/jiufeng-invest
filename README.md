# 玖峰金融工作台（Jiufeng FinBox）

**把散落的金融工具，装进一个桌面端。**

面向中国金融从业者的 [DSH Desktop](https://github.com/anywhere-labs/dsh-desktop)（DeepSeek Harness）插件集：把 AI 助手改造成金融工作台。

装完之后，DSH 的左侧栏变成金融工作流导航，对话里多出 21 个金融数据工具，Agent 换成带 89 个专业技能的「AI金融投研」预设。

---

## 安装

### 最省事 —— 一个 exe

1. 打开 **[官网下载页](https://report365.com.cn/)**，下载 `Jiufeng-Invest-Setup-1.1.10.exe`（151.6 MB，已含运行基座，不用先装 DSH）
2. 双击，跟着向导走。**全程不弹「用户账户控制」**——这一版起改为只为当前用户安装
3. 装完桌面只有一个「玖峰投研工作台」图标

> 只需要插件与技能？官网同一页有 1.2 MB 的插件包。
> **从 1.1.9 或更早版本升级**：请先在「设置 → 应用」里卸载旧版再装（安装位置从 Program Files 换到了用户目录），只需这一次；之后的小版本更新会在后台静默完成。

### 从 GitHub Releases / 源码

`jiufeng-invest-all-in-one.zip`（约 150 MB，内含 DSH Desktop 官方安装程序）解压后双击 `install.bat`；只需插件则用 `jiufeng-invest-plugin-only.zip`。

> **注意**：Releases 目前停在 v1.1.0，仓库代码已到 v1.1.10。想要新功能请走上面的官网 exe。

## ⚠️ 装完还需要你做一件事：配置模型

四层内容都会装好，但**模型要你自己出**。

作者本机用的是自己的 API Key，额度是个人的，没法分发。请打开 DSH Desktop 的设置，填上你自己的 Key（DeepSeek / 通义 / 智谱 等）。

不配也能打开界面、能看到全部卡片，但一发起对话就会报错。

> **联网搜索是可选增强，不是必需项。** 全部 21 个数据工具和 89 个技能**不配置搜索也能完整使用**——数据治理规则写死在技能模板里：拿不到的数据会如实标注「数据暂缺」，绝不编造。只有新闻、政策面、跨源舆情这类补充信息，配上搜索后才会更完整。搜索由 DSH 内置提供，需要一把**有余额的 DeepSeek Key**（单次搜索约 0.2~2 分钱）；若主模型用通义/智谱，需另配一个 DeepSeek Key。不配也不影响核心功能。

## 装完会看到什么

左侧栏会变成：

- **投研工作流** —— 7 个分析师工作流
- **专业工具** —— 104 个专业技能，分成 7 类
- **历史对话**

跟 Agent 对话时用的是「AI金融投研」预设 —— 89 个投研技能随时可调用，包括多空辩论、技术面诊断（MA / MACD / RSI / 布林带）、DCF 估值等。

21 个金融数据工具在对话里直接可用，不需要配置任何 API Key。股票代码搜索也开箱可用（走公开搜索接口，不需要账号）。

## 这套东西解决什么

**二级市场**：财务监控诊断、股票多空博弈、游资多专家研判、资产配置规划、基金对账核查
**一级市场**：投行业务全链路、项目筛选尽调

数据源覆盖东方财富 / 腾讯 / 雪球 / 新浪 / 凤凰，全部为公开 HTTP 接口，零第三方依赖、零 API Key。综合性联网搜索沿用 DSH 内置的 `web_search`（可选增强，见上方说明），插件不接管、不内嵌任何凭据。

## 环境要求

- DSH Desktop 稳定版 **2.0.10 ~ 2.0.13**（这一段的 Harness 恒为 `0.1.5-rc.2`，插件在版本间通用）
- **Beta 通道不兼容**：Beta 换成了 Harness `0.1.6-alpha.x` 且使用独立数据目录 `~/.dsh-beta`，请勿在 Beta 上安装
- 一键安装脚本需要 Windows + PowerShell 5.1（Win10 / Win11 自带）

## 安装脚本做了什么

`install.bat` 调用 `install.ps1`，一共装**四层**：

| 层 | 落点 | 内容 |
|---|---|---|
| 1 · 插件 | `~\.dsh\jiufeng-plugins\` + profile 的 `package.json` | 两个插件本体、依赖声明、`node_modules` junction |
| 2 · 预设 | `~\.dsh\.agent-presets\ai-finance\` | 投研 Agent 预设（89 个技能） |
| 3 · 配置 | `~\.dsh\settings.yaml`、`~\.dsh\icons\` | 默认 Agent 设为 `ai-finance`、铺品牌图标 |
| 4 · 外观 | DSH 安装目录 | 图标、品牌文案、受控更新守卫、prompt 收窄（需提权） |

改配置前都会自动备份（文件名带 `.bak-jiufeng-时间戳`）。

**重复运行是安全的**：已经正确的配置不会重复改，也不会重复备份。升级插件版本时，直接再双击一次 `install.bat` 即可。

想单独做第 4 层（或者 DSH 升级后补做），以管理员身份运行包内的 `app-patch.ps1`。

## 更新日志

### v1.1.10 · 2026-10-23

- **三档更新机制**：小更新在后台静默装好，装完只在右下角弹一个自动消失的小窗；大更新弹一次卡片、可以稍后；重大更新全屏提示，必须更新才能继续用。打扰程度由发布方在服务端手动指定（`silent` / `notice` / `force`），客户端只执行。
- **改为只为当前用户安装**：装到 `%LOCALAPPDATA%`，安装与以后每次更新全程不弹「用户账户控制」。从 1.1.9 及更早版本升级需要先卸载一次，之后不再需要手动干预。
- **专业工具卡片改造**：不再套用「会诊」那套语义，卡片标「专业工具 · 分类」、按钮为「开始」；需要整理资料或文件的工具可以在卡片里直接上传，插件取真实磁盘路径交给模型读原件处理，并保留原格式。
- **修复**：关闭使用数据上报后连更新提醒也收不到（1.1.0 ~ 1.1.3 的存量问题），上报开关与更新检查已解耦。

### v1.1.9 · 2026-10-22

- 使用数据上报默认开启且不弹窗，可在侧边栏「关于 · 使用数据上报」随时关闭；记录内容仅为使用时长、功能名与次数、报错信息。
