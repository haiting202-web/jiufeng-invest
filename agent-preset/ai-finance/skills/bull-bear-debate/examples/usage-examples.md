## 示例 1：客观模式 — 有数据支撑的完整辩论

**用户输入**：
> 帮我分析一下贵州茅台（600519），多空观点都说说

```
🐂 **看多方：价值发现者**
*一位相信价值终将回归的坚定多头*

📊 **核心论点**：
1. **品牌护城河极深** — 飞天茅台终端价长期稳定在2800-3000元/瓶，社交货币属性不可替代，品牌壁垒远超竞品
2. **现金流质量顶级** — 2024年经营性现金流/净利润比>1.2，预收账款余额持续增长，渠道打款积极
3. **高股息防御价值** — 当前股息率约3.2%，在消费龙头中属于高位，类债防御属性突出
4. **渠道改革红利释放** — i茅台直销占比突破45%，吨价提升效应仍在持续，单瓶净利润增厚
5. **估值回到合理区间** — 当前PE约22倍，处于近5年20%分位，相比2021年高峰70倍大幅回归

🚀 **潜在催化因素**：
- 白酒消费旺季（中秋国庆）备货行情
- 提价预期：出厂价已经2年未动，市场存在提价博弈
- 外资回流：北向资金持续增持消费龙头

🎯 **估值判断**：
- 当前估值水位：合理偏低，PE 22倍 vs 5年历史中枢30倍
- 目标区间：1800-2000元，对应25-28倍PE

📈 **置信度**：75/100

🐻 **看空方：风险哨兵**
*一位对任何乐观叙事都保持警惕的怀疑论者*

⚠️ **核心风险**：
1. **白酒行业总量见顶** — 2024年全国白酒产量同比继续下滑，喝白酒的年轻人比例在下降，消费场景持续收窄
2. **库存堰塞湖** — 社会库存估计超2年消费量，渠道实际开瓶率远低于出货量，真实消费被高估
3. **反腐和经济下行双重压制** — 高端白酒高度依赖政务商务消费，在"过紧日子"大背景下需求侧承压
4. **替代品侵蚀** — 威士忌/精酿/低度酒在年轻群体中的渗透率快速提升，白酒的"第一口"越来越难
5. **估值锚定失效风险** — 30倍PE的历史中枢建立在行业量价齐升时代，当行业从增量转存量，估值中枢可能进一步下移

🔻 **潜在利空触发**：
- 2025Q1季报显示直销增速放缓或预收款下滑
- 消费税改革落地（从量征收改为从价征收）
- 渠道价格倒挂加剧，经销商信心崩溃

📉 **下行测算**：
- 悲观情景（PE 18倍）：1500元，触发条件：Q2业绩低于预期+行业总量继续下滑
- 极端情景（PE 15倍）：1250元，触发条件：消费税改革+渠道价格崩盘

📊 **置信度**：70/100

|------|---------|---------|------|

💡 **裁决理由**：
当前茅台定价的核心矛盾不是"值不值22倍PE"，而是白酒行业是否已从"量价齐升"转向"量缩价稳"的新范式。看多方正确指出了品牌壁垒和现金流的防御价值；看空方的担忧更深远——如果行业总量持续萎缩，任何个体的壁垒都可能被行业洪流冲刷。建议以"偏多但低仓位"的心态参与。

⚠️ **风险提示**（偏多需警惕）：
1. Q2季报预收款变动 → 验证真实消费需求
2. 社会库存去化进度 → 终端开瓶率是关键先行指标
3. 消费税改革政策动向 → 如果落地将是系统性利空

🛡️ **风险等级**: **中**
```
