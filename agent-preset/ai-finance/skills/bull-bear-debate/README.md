# 股票多空辩论生成器

> 输入任意 A股 / 港股 / 美股代码，自动生成看多 vs 看空专业辩论，并给出独立裁决结论。

## 一句话介绍

让模型同时扮演「价值发现者」和「风险哨兵」两个角色，对目标股票做正反双向深度辩论，
最后由独立裁判给出加权裁决 —— 避免只看到一边的观点。

## 核心特性

- **双角色辩论** —— 看多辩手 vs 看空辩手，两条独立调用各自生成最强的正反论证
- **独立裁决** —— 裁判基于论据质量打分（论据 / 逻辑 / 数据 / 风险 四维加权），不预设立场
- **客观 / 主观双模式** —— 有数据时引用真实数字，无数据时基于行业逻辑推理
- **A股 / 港股 / 美股通用** —— 输入代码或名称即可触发
- **质量约束机制** —— 禁止稻草人论证、强制构建反方最强观点、置信度差距设上限
- **完整 / 精简两种输出** —— 完整模式用于研究，精简模式适配社交媒体发布

## 快速开始

```
帮我分析贵州茅台（600519）的多空双方观点
```

或更简洁：

```
茅台 正反辩论
```

技能会自动：

1. 搜索最新数据
2. 生成看多 / 看空双向论证
3. 独立裁判给出加权裁决
4. 输出完整分析报告

## 输出结构

完整模式包含五个板块：

1. **看多论证** —— 3~5 条核心论点 + 催化因素 + 估值判断
2. **看空论证** —— 3~5 条核心风险 + 利空触发 + 下行测算
3. **独立裁决** —— 四维加权评分 + 裁决结果
4. **风险提示** —— 反向风险 / 转机信号提醒
5. **互动引导** —— 投票 + 讨论话术
